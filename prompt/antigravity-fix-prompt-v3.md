# AntiGravity コード再設計 & 3大問題緊急改修指示書 (v3)

## 🚨 改修の背景と目的
現在発生している以下の3つの重大な不具合および物理プレイ感の乖離を根本解決するため、**「1000x1000 空間におけるカード・コアの独立物理オブジェクト化」**および**「視点切替・ドラッグ可能状態の再設計」**を実施してください。

---

## 1. 視点切り替え時の画面暗転バグの修正
### 症状
- ヘッダーの「相手の盤面」切替ボタンを押した際、画面全体が黒く暗転し描画が停止する。

### 原因と修正指示
1. **レンダリングループの例外ハンドリング**:
   - `currentViewMode === 'OPPONENT_BOARD'` への切り替え時に、相手側のオブジェクトデータが存在しない場合や未定義（`undefined` / `null`）プロパティにアクセスしたことで React のレンダリング例外が発生し、暗転（フォールバックなしエラー）しています。
   - `cards` や `players` のマッピング処理において、安全なオプショナルチェイニング (`card?.position?.x`) および デフォルト値補正 (`x ?? 500`) を全コンポーネントに徹底してください。
2. **Viewport 180度反転ロジックの修正**:
   - 暗転や非表示を引き起こす背景オーバレイや `opacity: 0` / `display: none` の誤適用を完全排除してください。
   - `OPPONENT_BOARD` 表示時は、`Viewport` または盤面描画コンテナの CSS 反転 (`transform: rotate(180deg)`) または 座標反転計算 (`1000 - x`, `1000 - y`) のみを安全に適用し、画面背景（キャンバス）が消去されないように保護してください。

## 2. カードが移動できない不具合の解消
### 症状
- フィールド上または手札のカードをドラッグしようとしてもカードが掴めず移動できない。

### 原因と修正指示
1. **@dnd-kit の Sensor と Pointer Events の調整**:
   - `@dnd-kit` の `PointerSensor` / `TouchSensor` のアクティベーション閾値（`activationConstraint: { distance: 5 }`）を設定し、クリックとドラッグが競合しないようにしてください。
   - カード要素の CSS に `pointer-events: auto` / `touch-action: none` を正しく適用し、上層の透明要素や DropTarget（`useDroppable`）がカードのポインターイベントを遮断しないように修正してください。
2. **所有権（Owner Authoritative）チェックの緩和**:
   - 自分の手札・自分盤面のカード (`ownerId === localPlayerId`) である場合に確実に `useDraggable` が `disabled: false` となるよう権限判定ロジックをチェックしてください。

## 3. コアの物理オブジェクト化 & 描画順（カード < コア）の再設計
### ユーザーからの要求
> 「コアが、カードに付与するようになっている。実際のプレイ感から変わらないように、描画順をカード＜コアの順にし、コアを自由にフィールドに移動できるようにすること。」

### 物理プレイ感に合わせたコア構造の再設計仕様
TCG「バトルスピリッツ」の実際の物理カードゲームの感覚通り、**コアはカードに紐づく内部数値データではなく、1000x1000 空間上に独立して存在する「青い透明トークンオブジェクト」**として再設計してください。

1. **描画順 (Z-Index / Layering) の厳格化**:
   - **カードの Z-Index**: `10 〜 50`
   - **コアの Z-Index**: `100 〜 200`（常にカードより上層に描画）
   - コアがカードの上に置かれても、コアがカードの背後に隠れたりカードコンテナの中にネストされたりせず、常に「カードの上に置かれた別個の移動可能オブジェクト」として上面に描画・表示されるようにしてください。

2. **コアの自由移動 (Free Placement)**:
   - コアはカードの上だけでなく、フィールドの空きスペース、リザーブ、ライフ、トラッシュ、ボイドなど **1000x1000 仮想空間内のあらゆる場所へ自由にドラッグ＆ドロップ移動可能** としてください。
   - コアをカードの上に置いた場合も、そのコア単体をクリックして別の場所（リザーブやトラッシュ、他のカード上）へ自由にドラッグ移動できるように `useDraggable` を各コアオブジェクトに独立設定してください。

3. **コア数カウントの動的算出**:
   - カードの「乗っているコア数 (`attachedCores`)」は、カードの AABB 範囲内に存在するコアオブジェクトの個数を動的に判定・カウントして表示（またはバッジ表示）してください。

## 4. 再設計後の確認用チェックリスト

- [ ] 自分のカードをマウス/タッチでスムーズに掴んでフィールドの自由な位置へ移動できるか
- [ ] コアがカードの上に重なった状態でも、コアが最前面（z-index高）に描画され、単体でつまんで自由に移動できるか
